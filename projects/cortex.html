Featured Project

Cortex

Cortex is an AI-powered language learning coach that delivers personalized practice across reading, listening, writing, speaking, and vocabulary, with adaptive feedback to help learners improve faster for real-world communication and exam success.

What It Does

  • Builds interactive practice experiences for reading, listening, speaking, writing, and vocabulary.
  • Adapts learning flow using learner profile, goals, and session memory.
  • Supports onboarding and exam-focused study planning workflows.
  • Exposes a structured API/MCP interface for extensible tooling.

Highlights

  • Personalized learner profile and progress memory
  • Widget-based lessons with fast iteration
  • Production-friendly backend architecture
